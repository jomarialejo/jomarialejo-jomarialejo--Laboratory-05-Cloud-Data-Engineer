# Laboratory Activity 5: The Cloud Data Engineer

## Mission Overview
In this lab, I deployed an S3-compatible object storage server using MinIO and Docker to simulate a cloud storage solution for a photo-sharing application. The activity covered the differences between block, file, and object storage, and demonstrated how to configure, access, and manage cloud storage buckets through a web console.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects (files) to the cloud
- Document cloud storage operations using Markdown
- Continue expanding a professional GitHub Cloud Computing Portfolio

## Tools Used
- KillerCoda Playground (Ubuntu)
- Docker
- MinIO (S3-compatible Object Storage)
- GitHub
- Markdown

## Skills Learned
- Deploying containerized cloud services with environment variables
- Managing object storage buckets through a web console
- Accessing services running on a remote host via port forwarding
- Documenting technical workflows in Markdown
